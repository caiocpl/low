`assets/` reúne o que foi recuperado dos PDFs: logotipo 2026 em vetor, retrato recortado, frames dos vídeos, logos das marcas e renders das versões anteriores para referência.

`html/` contém o gerador (`node build.js && node render.js`) que produz os PDFs com Inter embutida. `figma/finalizar-v4.js` finaliza o arquivo Figma (imagens, logotipo, textos) pelo plugin Scripter.
